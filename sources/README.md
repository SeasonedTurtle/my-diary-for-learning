# Sources

Put PDFs and notes in this folder. They stay on your computer.

This diary is a public repository, so copyrighted textbooks and course packets should not be committed. The published page is the summary you or an assistant write, in your own words, and that page can name the file that lives here.

A short PDF you wrote yourself may be committed beside its topic if you want it in the diary. Leave textbooks here, untracked.
