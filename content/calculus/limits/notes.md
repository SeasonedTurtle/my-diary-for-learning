# How to read the notation

- lim (x -> a) f(x) = L means: as x gets close to a, f(x) gets close to L.
- The function does not need a value at x = a.

# The factored example

- (x^2 - 1) / (x - 1) is undefined at x = 1.
- For every other x, it equals x + 1.
- The limit as x approaches 1 is 2.

# Both sides

- The limit exists only when the left-hand limit and the right-hand limit are equal.
- If they differ, say the limit does not exist. Do not average them.
