# Card
Front: What question does a limit ask?
Back: What value does the output approach as the input approaches some number?

# Card
Front: Does a function need a value at x = a for the limit as x approaches a to exist?
Back: No. The limit is about nearby values, not the value at the point.

# Card
Front: What is the limit of (x^2 - 1) / (x - 1) as x approaches 1?
Back: 2. Everywhere else the fraction equals x + 1, and x + 1 approaches 2.

# Card
Front: When do the two sides say a limit does not exist?
Back: When the left-hand limit and the right-hand limit are not equal.
