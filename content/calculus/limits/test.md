# Question
Prompt: A limit describes which of these?
Choices:
- The value the output approaches
- The value the function must equal at that exact input
- The slope of every line
Answer: The value the output approaches
Why: The function might be undefined at the point. The limit only cares about nearby outputs.

# Question
Prompt: What is the limit of (x^2 - 1) / (x - 1) as x approaches 1?
Choices:
- 2
- 0
- The limit does not exist
Answer: 2
Why: For every x other than 1, the fraction equals x + 1, which approaches 2.
