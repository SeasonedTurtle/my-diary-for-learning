A limit asks a careful question: as the input gets closer and closer to some number, what number does the output get closer to?

Take the function that sends x to 2x. As x gets close to 3, 2x gets close to 6. The limit is 6. Nothing surprising happened, because 2x is perfectly happy at x = 3.

Limits matter more when the function is not happy at that exact spot. Look at (x^2 - 1) / (x - 1). If you plug in x = 1, the top and the bottom are both 0, and 0/0 is not a number. The function has no value at x = 1. Everywhere else, (x^2 - 1) / (x - 1) equals x + 1, because x^2 - 1 = (x - 1)(x + 1). As x gets close to 1, x + 1 gets close to 2. The limit is 2, even though the function never arrives at x = 1.

A limit does not ask what the function equals at the point. It asks what value the function approaches.

The two sides have to agree. Approaching 1 only through smaller numbers is the left-hand limit. Approaching only through larger numbers is the right-hand limit. The limit exists when those two sides approach the same number.
